# expense_tracker

A minimal Android expense tracker built with Flutter. Log expenses with
short text commands (e.g. `fare 60`), track a running "current" period,
close it out to start a new one, and review current vs. previous periods
in a history view. See [SPEC.md](SPEC.md) for the full feature spec.

This project is vibecoded — built by prompting Claude Code rather than
writing the implementation by hand.

## Setup

See [SETUP.md](SETUP.md) for setting up the Flutter/Android toolchain
(via FVM) and running the app.
